# 99-MYCHART — 내 기록 차트

BTC 심리차트(`smoothcrush808-cmd/BTC`)의 복사본에 **내 기록(노션 af WC)**을 시간축 위 점으로 띄운다.
점을 누르면 그때 쓴 글·캡쳐·Claude 댓글이 페이지 안 팝업으로 뜬다. 상단 「내 기록」 버튼으로 켜고 끈다.
기록은 암호화본만 올라간다(`data/notes.enc`, `data/img/*.bin` — `tools/build_notes.py`). 첫 방문에 비밀번호.
오른쪽 아래 모서리에 지금 시각(KST)을 띄워 캡쳐에 같이 찍히게 했다.
원본과 같은 주소 공간이라 저장 키는 `myChart.*`, Gist 파일은 `my-chart.json`(원본 그림과 섞이지 않는다).
가짜 샘플로 보기: 주소 뒤 `?sample=1`.

# BTC 심리차트

바이낸스 현물 BTC/USDT 캔들을 2022년부터 지금까지 보고, 표시를 남기는 개인용 차트.
지표 없이 캔들로만 읽는다. GitHub Pages에 그대로 올리는 정적 페이지 (빌드 없음).

- `index.html` — 화면·스타일
- `app.js` — 시세 받기, 실시간, 그리기 도구, 저장

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 봉 간격 | 상단 5분 / 15분 / 1시간 (키 `1` `2` `3`) |
| 날짜 이동 | 날짜 버튼 → KST 날짜·시각 입력 (키 `G`). 그 봉이 가운데, 세로 점선 표시 |
| 시점 북마크 | 날짜(📅) 버튼 → `지금 시점 저장` (이름 선택). 목록을 누르면 저장한 시각·봉 간격·확대 그대로 이동, ✕로 삭제. 내보내기/가져오기에 함께 포함 |
| 최신으로 | 최신 버튼 (키 `L`) |
| 과거 보기 | 왼쪽으로 끌면 자동으로 더 받음 (1000봉씩) |
| 그리기 | 도구 버튼 → 차트 탭 1번 (수평선·수직선·점·레이) / 2번 (박스). 한 번 그리면 커서로 돌아감. 수직선은 시간축에 시각 라벨 |
| 자유선 | 자유선(P) 버튼 → 끌어서 그리기. 손을 떼도 도구가 유지돼 여러 획 가능, `완료`로 끝. 그리는 동안 차트는 고정. 선택 후 끌어서 이동, 색·굵기 변경 |
| 텍스트 | 텍스트(T) 버튼 → 차트 탭 → 글 입력(최대 60자). 크기 4단계(작게·보통·크게·아주 크게, 마지막 크기 기억). 탭해서 선택하면 `글 수정`, 크기·색 변경, 끌어서 이동 |
| 지우기 | 지우기 버튼 → 지울 그림 탭 |
| 되돌리기 | 되돌리기 버튼 또는 `Ctrl+Z`(맥 `⌘Z`). 그리기·지우기·이동·색·글 수정·전체 삭제·가져오기를 최대 50단계 (새로고침하면 기록은 비워짐) |
| 수정 | 도구 없이 그림을 탭 → 선택(주황 동그라미). 몸통을 끌면 이동, 동그라미를 끌면 그 꼭짓점만 이동. 빈 곳 탭 또는 `완료`로 끝, `삭제`로 지움 (PC는 `Delete`) |
| 취소 | 안내 바의 취소, 또는 `Esc` |
| 색 | 도구를 고르거나 그림을 선택하면 안내 바에 10색 표시 → 탭해서 변경. 도구별로 마지막 색을 기억 |
| 선 굵기 | 수평선·수직선·레이·박스·점: 안내 바의 굵기 4단계(얇게·보통·굵게·아주 굵게, 점은 크기). 도구별로 마지막 굵기 기억, 선택한 그림도 바로 변경 |
| 단축키 | `H` 수평선 · `V` 수직선 · `B` 박스 · `D` 점 · `R` 레이 · `P` 자유선 · `T` 텍스트 · `E` 지우기 · `Ctrl+Z` 되돌리기 |
| 캡처 | 차트 오른쪽 아래 📷 버튼 (PC `C`). 그림·축 포함 + 위에 봉 간격·시각 표시. 폰: `공유…` → 카톡·Claude·메모 등 (사진첩엔 저장 안 됨) / `복사`. PC: 누르면 바로 클립보드 복사, `파일 저장`도 가능 |
| 와이드 (폰) | 상단 ▭ 버튼 → 화면이 90° 돌아감, 폰을 왼쪽으로 눕혀서 보기. 다시 누르면 원래대로. 켜 둔 상태는 기억함 (폰을 실제로 가로로 돌리면 자동으로 꺼짐) |

**전체 화면으로 보기 (iPhone)**: 사파리에서 공유 버튼 → `홈 화면에 추가` → 홈 화면의 '심리차트' 아이콘으로 열면
주소창·탭 막대 없이 화면 전체를 쓴다. (사파리 안에서는 웹페이지가 전체 화면을 켤 수 없다.)
홈 화면 앱은 사파리와 저장 공간이 따로라서, 사파리에서 그린 그림은 내보내기 → 가져오기로 옮긴다.

**기기 간 자동 동기화 (GitHub)**: 저장 버튼 → `GitHub 열쇠 만들기` 링크에서 `gist` 권한 토큰 생성 → 붙여넣고 `연결`.
아이폰·PC·갤럭시탭에 같은 열쇠를 한 번씩 넣으면 그림·북마크가 비공개 Gist 하나(`btc-psych-chart.json`)로 맞춰진다.
바꾸면 2초 뒤 올리고, 앱을 열 때·화면으로 돌아올 때·1분마다 받아온다. 항목마다 마지막 수정 시각으로 합치고,
지운 것은 '지움 기록'으로 남겨 다른 기기에서 되살아나지 않는다. 와이드·색 같은 화면 설정은 기기마다 따로.
열쇠는 그 기기 브라우저에만 저장된다.

그림은 기기 브라우저(localStorage)에 자동 저장된다. 폰 ↔ PC 이동은 저장 버튼에서
파일(.json) 또는 텍스트로 내보내고 다른 기기에서 가져오기 (합치기, 중복 없음).

## 시세 출처
